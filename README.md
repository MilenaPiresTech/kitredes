# Kit Redes

Sistema web desenvolvido para gerenciamento de kits educacionais voltados ao ensino prático de Redes de Computadores.

## Objetivo

Facilitar a organização e o gerenciamento de equipamentos, kits e atividades práticas utilizados no ensino de Redes de Computadores.

## Tecnologias

- Python
- Django
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Funcionalidades

- Cadastro e gerenciamento de equipamentos;
- Organização por categorias;
- Upload e exibição de imagens;
- Gerenciamento de kits e atividades (em desenvolvimento).
